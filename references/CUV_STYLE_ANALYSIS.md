# 《圣经》和合本文体分析与句式语料

## 资料范围

本笔记以维基文库收录的《圣经（和合本）》为主要语料，抽查以下文类：

- 摩西五经：创世记、出埃及记、申命记
- 历史书：撒母耳记上、列王纪上
- 诗歌智慧书：诗篇、箴言、传道书
- 先知书：以赛亚书、耶利米书
- 福音书：马太福音、路加福音、约翰福音
- 教会历史：使徒行传
- 书信：罗马书、哥林多前书、雅各书
- 异象文学：启示录

原始页面使用繁体字和旧式标点。本文为项目使用方便改用简体字与现代标点；句法和措辞不作现代化润色。

## 核心结论

和合本风格不等于文言文，也不等于在现代句子中加入“乃、遂、其、曰”。其最鲜明的特征是：

1. **旧译白话句法**：句子并不极端简短，而是反复说明人物、关系、条件、归属和后果。
2. **连续记事节奏**：常用“那时、于是、及至、听见这话、他就、不料”等串起事件。
3. **重复主语**：现代中文常省略主语，和合本却常再次说出人物或“那人、他、众人”。
4. **话语与反应相连**：不是孤立地写“某某说”，而是“听见这话，就开口……”“说完这话，于是……”。
5. **条件和后果成对出现**：大量使用“若……就……”“凡……的……必……”“好叫、免得、以致”。
6. **复沓与平行**：同一个句法连续出现，造成宣告、训诲、审判或诗歌般的节奏。
7. **郑重的关系表达**：常把简单意思扩成“在谁眼前、从谁手中、所说的话、所定的日期、所作的工”。
8. **强烈对照**：常见“不是……乃是”“本来……如今”“尚且……何况”“你……我……”。
9. **具体名物不回避**：人物、地点、器物、数目和行动往往写得具体；庄严感来自句法，不来自把现代物品全部换成古代物品。
10. **不同文类有不同声音**：历史叙事、诗篇、箴言、先知宣告、福音对白、书信论证、启示异象不能只用一套“古词表”。

因此，翻译器的目标应是：**重建和合本的句法关系与文类声音，而不是对原句做文言词替换。**

## 一、叙事推进

### 1. 人物和场景出场

常见结构：

- 有一个人，是从……来的，名叫……
- 那时……
- 当那些日子……
- 这事以后……
- 后来……
- 到了时候……
- 日期满了……

作用：先把人物、来历、时间和地点郑重摆出来，再进入事件。

现代文案转换方向：

- “小王下午去办公室找经理。”
- 可展开为：“到了下午，小王就起来往办公室去，要在那里见经理。”

### 2. 看见、听见和突转

常见结构：

- 举目观看……
- 看哪……
- 不料……
- 听见这话……
- 话还没有说完……
- 及至……的时候……

代表短句：

| 出处 | 句式锚点 | 可提取机制 |
| --- | --- | --- |
| 创世记 18:2 | “举目观看，见有三个人……” | 观察后立即进入行动 |
| 创世记 15:17 | “日落天黑，不料……” | 时间＋意外显现 |
| 马太福音 13:25 | “及至人睡觉的时候……” | 阶段推进＋转折 |
| 使徒行传 10:44 | “彼得还说这话的时候……” | 发言未完，事件已经发生 |
| 使徒行传 2:37 | “众人听见这话，觉得扎心……” | 听见＋反应＋追问 |

### 3. 行动链条

和合本常把动作写成一连串“就、又、便、于是”：

- 他一见，就……
- 他听见，就……
- 他又……
- 于是……
- 那人却……

这种写法不追求现代小说式变化，而以重复连接造成记事感。

### 4. 完成、验证与收束

代表短句：

- “神说，要有光，就有了光。”（创世记 1:3）
- “事就这样成了。”（创世记 1章多次）
- “人就拿刀来。”（列王纪上 3:24）
- “所说的话没有落空。”（多处同类表达）

可提取的结构：

```text
宣告／命令 → 人物照样而行 → 结果显明 → 事就这样成了
```

这类收束特别适合项目交付、执行命令、交易完成、程序修复和承诺兑现。

## 二、人物对白

### 1. 对白不是原句加一个“他说”

和合本对白常带完整的说话动作和关系：

- 某某对某某说……
- 某某回答说……
- 他就开口教训他们说……
- 他复问说……
- 他向那人陈明……
- 他求他说……

真正的辨识度仍在引号内部：条件、反问、复沓、归属和后果必须进入人物所说的话。

### 1.1 连续对话不会机械重复完整说话标签

对照和合本连续对白可见，说话标签承担的是“消除歧义和推进动作”，不是每句都重新报出完整人物关系。

- 约翰福音 4:7-26 首次交代对象时写“耶稣对她说”，进入两人问答后迅速缩成“妇人说”“耶稣回答说”“耶稣说”。
- 马太福音 4:1-11 按场面动作推进：“那试探人的进前来，对他说”“耶稣却回答说”“魔鬼又带他……对他说”“耶稣说”。人物关系已经清楚后，不重复双方姓名。
- 撒母耳记上 17:41-49 首次写“非利士人对大卫说”，同一人继续发言只写“非利士人又对大卫说”；大卫的长篇回应只设一个“大卫对非利士人说”。
- 创世记 18:1-15 常把动作与言语接成一句：“他一见……俯伏在地，说”；简短轮替则直接写“他们说”“他说”“那位说”。

因此机械渲染应遵守：

1. 一场对话首次出现或受话人改变时，才使用“甲对乙说”。
2. 两人轮替时优先使用“甲回答说”“乙说”，不重复受话人。
3. 同一人物连续几项陈说合并在一个引语标签下；若语气改变，才用“又问说、又吩咐说、又大声说”。
4. 叙事已经写出“某人听见这话、转向某人、怒气发作”时，下一句直接接“说／回答说／大声说”，不再重复姓名。
5. “开口说”只用于沉默后郑重发言、公开教训或需要刻意标记发言开始的场面，不作普通 `said` 的默认翻译。
6. 不随机轮换“宣明、陈明、晓谕、开口、回答”等词；应由发言功能和上下文决定。

### 1.2 段落结尾通常还有一层结果、去向或训诫

和合本故事很少在最后一个动作刚出现时突然截断，常再补一层收束：

- 去向并列：“耶和华与亚伯拉罕说完了话就走了；亚伯拉罕也回到自己的地方去了。”（创世记 18:33）
- 行程与落脚：“他们一同起身往别是巴去，亚伯拉罕就住在别是巴。”（创世记 22:19）
- 结果与后续：“于是，魔鬼离了耶稣，有天使来伺候他。”（马太福音 4:11）
- 劝诫落点：“你去照样行吧。”（路加福音 10:37）
- 总结公式：“主的道大大兴旺，而且得胜，就是这样。”（使徒行传 19:20）
- 完工状态：“天地万物都造齐了……神造物的工已经完毕。”（创世记 2:1-2）

机械渲染不能为了完整感虚构后续，只能按输入已经支持的结局选择：

- 已完成、恢复、办妥：`这事就这样成了。`
- 已离场、冲突已有明确结果：`这事的结局，就是这样。`
- 普通记事已结束：`所记的事，就是这些。`
- 通知、条例、命令：`所要晓谕的／所列的条例／所吩咐的话，就是这些。`
- 只有威胁、问题、计划而尚无结果的片段，不得伪造完成式结尾。

### 2. 问句扩大成郑重审问

代表短句：

- “我是什么人，竟能去见法老……呢？”（出埃及记 3:11）
- “你手里是什么？他说，是杖。”（出埃及记 4:2）
- “耶和华是谁，使我听他的话……呢？”（出埃及记 5:2）
- “你们中间谁是没有罪的……”（约翰福音 8:7）
- “这有什么益处呢？”（雅各书 2:16）

常用框架：

- 我是什么人，竟能……呢？
- 这是甚么缘故呢？
- 你作的是什么事呢？
- 岂不……么？
- 谁能……呢？
- 有什么益处呢？

### 3. 请求写成蒙恩、许可和交付

代表短句：

- “我若在你眼前蒙恩，求你……”（创世记 18:3）
- “求你容我们……”（出埃及记 5:3）
- “求你赐我智慧，可以判断……”（列王纪上 3:9）

现代文案转换方向：

```text
“借我点钱”
→ “我若在你眼前蒙恩，求你从手中取些钱借给我；
   因为我如今有所缺乏，好叫周转的事得以成就。”
```

### 4. 对抗写成双方对照

代表短句：

- “你来攻击我，是靠着刀枪……我来攻击你，是靠着……”（撒母耳记上 17:45）
- “你有信心，我有行为……”（雅各书 2:18）

核心不是具体宗教内容，而是：

```text
你凭什么而来；我凭什么而来。
你所有的是什么；我所有的又是什么。
```

这非常适合改写影视台词中的立场宣告、身份压制和强弱对峙。

### 5. 标志性台词保留意象，不保留原句

原句：

> 在我面前，是龙得盘着，是虎得卧着。

应保留“我面前、龙—盘、虎—卧”的对应关系，但重建和合本句法：

> 我实在告诉你，凡来到我面前的，无论他自比为龙，或自称为虎，都不可任意而行；龙必要屈身盘伏，虎也必要俯首而卧。

这比直接引用原话更符合“圣经体”，同时仍能一眼认出原意。

## 三、条件、因果与递进

### 1. 若……就……

- “你们祈求，就给你们；寻找，就寻见……”（马太福音 7:7）
- “你们寻求我，若专心寻求我，就必寻见。”（耶利米书 29:13）
- “信心若没有行为，就是死的。”（雅各书 2:17）

作用：把建议、规则和行为后果写成不可忽视的关系。

### 2. 凡……的……必……

- “凡祈求的，就得着……”（马太福音 7:8）
- “凡遵守……的有福了。”（启示录 22:7）
- “凡事包容，凡事相信，凡事盼望，凡事忍耐。”（哥林多前书 13:7）

作用：把个别事件扩大成一般原则，是和合本节目效果的重要来源。

### 3. 尚且……何况……岂不……

马太福音 7:11 的推理方式：

```text
你们尚且知道……
何况……
岂不更……吗？
```

适合把普通反驳、比较和“连这个都……”式吐槽写得极其郑重。

### 4. 好叫、免得、以致

这些词把目的和后果说得特别完整：

- 好叫事情得以成就
- 免得错过所定的时候
- 以致众人不能明白

现代中文常省略这些关系，和合本却倾向于明确说出。

## 四、复沓、排比与对照

### 1. 同句式连续重复

代表句式：

- “有晚上，有早晨……”（创世记 1章）
- “生有时，死有时；栽种有时，拔出……也有时。”（传道书 3:2）
- “祈求……寻找……叩门……”（马太福音 7:7）
- “患难生忍耐；忍耐生老练；老练生盼望。”（罗马书 5:3-4）
- “凡事包容；凡事相信；凡事盼望；凡事忍耐。”（哥林多前书 13:7）

### 2. 不是……乃是……

代表结构：

- “不是要定世人的罪，乃是要叫世人……。”（约翰福音 3:17）
- “不是我作的，乃是……”（罗马书 7:20）

适合澄清、反转、甩锅、辩解和定义。

### 3. 本来……如今……反倒……

代表结构：

- “素来饱足的，反作佣人求食……”（撒母耳记上 2:5）
- “我所愿意的善，我反不作；我所不愿意的恶，我倒去作。”（罗马书 7:19）

适合打脸、反差、失败和自我矛盾。

## 五、诗篇式呼告与情绪

诗篇的特点不是“悲伤词多”，而是明确呼告对象、重复问题、陈说处境，再转向盼望或判断。

代表短句：

| 出处 | 句式锚点 | 风格机制 |
| --- | --- | --- |
| 诗篇 23:1 | “耶和华是我的牧者，我必不至缺乏。” | 身份关系＋必然后果 |
| 诗篇 22:1 | “我的神，我的神，为什么离弃我？” | 重复呼告＋追问 |
| 诗篇 19:1 | “诸天述说……穹苍传扬……” | 两个主体平行作证 |
| 诗篇 42:7 | “深渊就与深渊响应。” | 意象重复＋声音呼应 |

适合：第一人称崩溃、委屈、疲倦、孤独、等待和赞叹。

不适合：没有强烈情绪的普通通知和说明。

## 六、箴言式格言与人物类型

箴言常用两句对照，把行为与后果压缩成判断：

- “回答柔和，使怒消退；言语暴戾，触动怒气。”（箴言 15:1）
- “敬畏耶和华是知识的开端……”（箴言 1:7）
- “铁磨铁，磨出刃来；朋友相感，也是如此。”（箴言 27:17）
- “懒惰人说，外头有狮子……”（箴言 22:13）

可提取结构：

```text
智慧人怎样；愚昧人怎样。
勤快的人怎样；懒惰人怎样。
前一种言语产生什么；后一种言语又产生什么。
```

适合观点、吐槽、经验总结和人物行为模式；不得凭空给现实人物定罪。

## 七、传道书式循环与虚空感

代表短句：

- “虚空的虚空……凡事都是虚空。”（传道书 1:2）
- “日光之下并无新事。”（传道书 1:9）
- “凡事都有定期，天下万务都有定时。”（传道书 3:1）

风格机制：

- 同一名词层层重复
- 把个别经验扩大到“凡事、天下万务、日光之下”
- 用循环、对称和时间对举制造宿命感

适合反复加班、循环报错、拖延、版本轮回和“又是同一件事”的节目效果。

## 八、先知式宣告

先知书常见：权威来源＋命令／警告＋原因＋后果。

代表短句：

- “你们当站在路上察看，访问古道……”（耶利米书 6:16）
- “我知道我向你们所怀的意念……”（耶利米书 29:11）
- “那等候耶和华的，必从新得力……”（以赛亚书 40:31）
- “我们都如羊走迷，各人偏行己路。”（以赛亚书 53:6）

适合公告、领导讲话、警告、愿景、承诺和重大结论。

不得把普通建议都写成绝对权威的“晓谕”，除非原文确有发布权。

## 九、福音书式教训、比喻与对白

### 1. 有福了……因为……

马太福音 5章的结构：

```text
某种人有福了；
因为他们必得到某种结果。
```

适合把人物类别和结果一本正经地联系起来。

### 2. 设问后反问

- “谁有儿子求饼，反给他石头呢？”（马太福音 7:9）
- “你们中间谁是没有罪的……”（约翰福音 8:7）

适合怼人、拆穿和把常识说成严肃论证。

### 3. 比喻起手

- “天国好像……”（马太福音 13章多次）
- “有一个财主……”（路加福音多处）

转换现代文案时，可以使用“这事好像……”进行比喻，但比喻必须来自原文已有关系，不能新增事件。

## 十、书信式论证

书信常用明确听众、逐层论证、反问和自我辩论。

代表短句：

- “不但如此……”（罗马书 5:3）
- “故此，我所愿意的善，我反不作……”（罗马书 7:19）
- “你有信心，我有行为……”（雅各书 2:18）
- “这有什么益处呢？”（雅各书 2:16）
- “我亲爱的弟兄们……快快地听，慢慢地说……”（雅各书 1:19）

适合观点、解释、辩论、产品理由和技术因果；没有听众时不要机械加入“弟兄们”。

## 十一、启示录式异象

代表短句：

- “看哪，我必快来。”（启示录 22:7）
- “我是阿拉法，我是俄梅戛……”（启示录 1:8）
- “我又看见一个新天新地……”（启示录 21:1）
- “我听见有大声音……”（启示录 21:3）

风格机制：

- “我又看见、我听见、看哪”反复推进
- 自我宣告和首尾对称
- 巨大的视觉、声音和时间尺度

仅适合输入本身已有视觉、发布、重大变化或夸张气势的场景。普通小事若使用，应控制在节目效果范围内，不得新增神迹或世界毁灭。

## 十二、著名与高辨识度句式清单

以下短句只作为风格锚点，不应在每次输出中照抄：

1. “起初……”（创世记 1:1）
2. “神说……就有了……”（创世记 1:3）
3. “事就这样成了。”（创世记 1章）
4. “举目观看……”（创世记 18:2）
5. “我若在你眼前蒙恩，求你……”（创世记 18:3）
6. “我是什么人，竟能……呢？”（出埃及记 3:11）
7. “你手里是什么？”（出埃及记 4:2）
8. “容我的百姓去。”（出埃及记 5:1）
9. “你来攻击我……我来攻击你……”（撒母耳记上 17:45）

### 12.1、补充名句：按功能使用的第二层锚点

下列句子辨识度更高，适合用来判断输出是否真的接近和合本；它们仍然只是句法、节奏和语气的参考，不能机械拼接或逐句仿写。

**福音宣告与身份关系**

- “神爱世人，甚至将他的独生子赐给他们，叫一切信他的，不至灭亡，反得永生。”（约翰福音 3:16）

- “万事都互相效力，叫爱神的人得益处。”（罗马书 8:28）

**苦难、盼望与诗歌复沓**

- “我虽然行过死荫的幽谷，也不怕遭害，因为你与我同在。”（诗篇 23:4）

这些补充句子的共同作用不是提供“古词”，而是提供可迁移的关系结构：

```text
身份宣告 → 关系归属 → 条件或转折 → 必然结果
劝勉命令 → 具体行动 → 应许或警戒
眼前苦难 → 重复呼告 → 仍然信靠或盼望
两种道路/两种结果 → 对照 → 判语
```

## 十三、适用于翻译器的转换算子

后续提示词应优先调用“算子”，而不是固定词表。

### 算子 A：现代叙述 → 记事推进

```text
人物／时间出场
→ 看见或听见
→ 开口或行动
→ 对方反应
→ 于是／及至
→ 原结局
```

### 算子 B：普通台词 → 郑重关系句

```text
保留说话意图
→ 加入说话人与受话人的关系
→ 加入条件、归属或后果
→ 使用第一人称复沓或间接转述
→ 删除原句连续措辞
```

### 算子 C：观点 → 书信／训诲论证

```text
先陈明主题
→ 反问
→ 对照
→ 因为／所以
→ 尚且／何况
→ 结论
```

### 算子 D：通知／规则 → 晓谕／条例

```text
论到某事
→ 所定的时间或对象
→ 你们当／不可
→ 若不如此
→ 免得／以致
```

### 算子 E：情绪 → 诗篇式呼告

```text
我的心哪／为何
→ 重复处境
→ 陈说所受影响
→ 仍保持原文结论
```

### 算子 F：列表 → 点数与各从其类

```text
所当预备的记在下面
→ 第一、第二、第三
→ 各从其类
→ 一样也不可遗漏
```

## 十四、必须避免的伪圣经体

1. **只换古词**：“他说”改成“其曰”，“去了”改成“遂往”。这是普通文言化，不是和合本。
2. **原台词照抄**：在原台词前加“我实在告诉你”仍不够；台词内部必须重造。
3. **晓谕、咒诅滥用**：普通建议不是晓谕，普通报错不是咒诅。
4. **全篇同一种句式**：反复使用“于是、便、又”而没有条件、反问、归属和复沓，风格仍弱。
5. **为了圣经感加戏**：不得补人物内心、神迹、围观者、预言、报应和原文没有的结局。
6. **写成古装小说**：避免“少顷、未几、遂、曰、吾、汝、矣、焉”成为主要风格来源。
7. **抽象掉名台词**：龙盘、虎卧之类对象—动作映射必须保留，只重造句法。
8. **各文类混用**：技术说明不必写成战斗故事，通知不必写成哀歌，普通清单不必出现异象。

## 十五、项目应用建议

下一版提示词不应继续无限增加零散规则，而应采用三层结构：

1. **先选和合本文类**：记事、诗篇、箴言、先知宣告、福音教训、书信论证、启示异象。
2. **再选三至五个转换算子**：叙事推进、对白重造、条件后果、复沓排比、关系扩张等。
3. **最后做质量门槛**：
   - 是否仍照抄原台词；
   - 是否只是文言化；
   - 是否至少有多种和合本句法；
   - 是否保持人物、数字、动作和结局；
   - 是否新增原文没有的心理与事件。

著名句式只能作为强度标尺和句法来源，不能作为所有题材反复套用的固定模板。
